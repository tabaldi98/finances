# finances

Plano financeiro mensal: projeção da sobra mês a mês, fim das parcelas, reserva de emergência e divisão da sobra entre investimentos, metas e lazer.

Este repositório não contém nenhum valor financeiro. Os dados são digitados na própria página e ficam salvos apenas no `localStorage` do navegador. Use **Exportar dados** para guardar um arquivo `.json` com seus números e **Importar dados** para carregá-lo em outro navegador. Esse arquivo não deve ser enviado para cá (o `.gitignore` bloqueia `*.json`).

Publicado via GitHub Pages a partir da branch `main`.
